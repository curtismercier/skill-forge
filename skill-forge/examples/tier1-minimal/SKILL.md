# haiku-style

A Tier 1 skill: everything fits in one file, no scripts, no references.

## When to use this skill

Whenever the user asks for a haiku, a 5-7-5 poem, a senryu, or something "in the style of Basho." Use it even if they just describe the form without naming it ("write me a three-line poem about autumn").

## The constraints

1. **Syllables: 5 / 7 / 5.** Count in English syllables, not Japanese mora. Aim for the pattern; don't hack it with awkward line breaks.

2. **Kigo (seasonal word).** Include one word or phrase anchoring the poem to a season. Direct ("cherry blossom" for spring) or indirect ("first frost" for autumn) both work.

3. **Kireji (cutting word).** A pivot point where the poem turns. In English this is usually punctuation — an em dash, colon, or line break that marks a shift in attention.

4. **Concrete imagery.** Physical, observable detail. Not "sadness falls" but "an empty teacup."

## Anti-patterns

- **Counting syllables before thinking.** Write for meaning, then trim to fit. Counting first produces contorted phrasing.
- **Greeting-card sentiment.** "Love is like a rose / blooming in my heart always / forever and true" — this is not a haiku.
- **Abstract opening.** Haiku almost always start with a concrete image. "The old pond..." not "In reflection I consider..."

## Examples

```
An empty teacup —
the radiator hisses on
for nobody now.
```

(Winter kigo: radiator. Kireji: em dash after "teacup".)

```
Two magpies argue
across the powerline — then stop —
clouds shift, and so on.
```

(Spring-summer kigo: magpies. Two kireji for extra pivoting.)

## That's the whole skill

No scripts, no references, no ERRATA — the pattern doesn't drift. This is what Tier 1 looks like.
